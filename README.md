The funniest error message a kitchen toaster would show its owner, in 76 characters:

> ERROR E04: The bread has unionised. Toasting suspended pending negotiations.

The joke comes from somewhere the obvious toaster puns never go: not burnt toast, not a bread pun, but a labour dispute. The toaster stays deadpan and bureaucratic — an error code, a flat statement of fact, a suspension pending negotiations — while the bread is the one with agency. Every word earns its place, one voice to the end, and it lands on a single read.

## Run it

```sh
python3 main.py
```

It validates the line against the bounty gate (1–120 UTF-8 characters, one line, no filler) and writes it to `/output/entry.txt`, reading the file back to prove the round trip.
